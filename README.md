# Lee & Praew · Wedding RSVP

## โครงสร้าง
- `index.html`   หน้าเว็บ (HTML/CSS/JS) — แก้ข้อความ/สีที่ตัวแปร `:root` ด้านบนไฟล์
- `config.js`    **ที่เดียวสำหรับตั้งค่า**: วันงาน, ลิงก์ Google Sheet (`scriptUrl`), ลิงก์แผนที่, รูปทุกช่อง
- `photos/`      รูปทั้งหมดที่ใช้ในเว็บ (hero, print1, print2, strip1-3)
- `assets/logo.png`  โลโก้
- `apps-script.gs`   โค้ดรับคำตอบ RSVP เข้า Google Sheet
- `qr/make_qr.py`    สร้าง QR: `python make_qr.py https://ลิงก์จริง` (ใส่ `--logo` ถ้าต้องการโลโก้กลาง)

## เปลี่ยนรูป (ง่ายสุด): โหมดแก้รูป
1. เปิดเว็บด้วยลิงก์ต่อท้าย `?edit` เช่น `https://ชื่อคุณ.github.io/repo/?edit`
2. กดปุ่ม "เปลี่ยนรูป" บนรูปที่ต้องการ แล้วเลือกรูปจากเครื่อง (ย่อขนาดให้อัตโนมัติ)
3. ลากบนรูปเพื่อเลื่อนจุดโฟกัส (ส่วนของรูปที่อยากให้เห็น)
4. กด "ดาวน์โหลดไฟล์ที่แก้" จะได้ไฟล์รูป (เช่น hero.jpg) และ config.js
5. ไปที่ GitHub: อัปโหลดรูปทับในโฟลเดอร์ `photos/` และอัปโหลด `config.js` ทับที่ราก repo → Commit
(โหมดนี้ใช้ดูตัวอย่างบนเครื่องคุณเท่านั้น แขกเปิดเว็บแล้วไม่เห็นการเปลี่ยนจนกว่าจะอัปโหลดบน GitHub)

## เปลี่ยนรูปด้วยมือ
อัปโหลดรูปใหม่ลงโฟลเดอร์ `photos/` โดยใช้ชื่อไฟล์เดิม (ทับของเก่า) หรือเปลี่ยนชื่อไฟล์ใน `config.js`
แนะนำรูป JPG ด้านยาวไม่เกิน 1600 px

## ลิงก์เฉพาะแขก
ต่อท้าย URL ด้วย `?to=ชื่อแขก` ชื่อจะขึ้นบนซองและกรอกในฟอร์มให้อัตโนมัติ
ข้ามซองเปิดการ์ด: `?skip`

## เผยแพร่
อัปโหลดทั้งโฟลเดอร์ขึ้น GitHub แล้วเปิด Settings > Pages (Deploy from a branch → main → /root)


## หน้าแอดมิน (admin.html)
เปิด `https://<user>.github.io/LP_Wedding/admin.html` เพื่อแก้ข้อความ รูป สี เพลง วิดีโอ ได้พร้อมดูตัวอย่างสด
- กด "เผยแพร่ขึ้นเว็บ" แล้วใส่ GitHub token (Contents: Read and write) หรือกด "ดาวน์โหลดไฟล์" แล้วอัปโหลดเองที่ GitHub
- ข้อความทั้งหมดอยู่ใน `config.js` (`window.SITE`) — อย่าลืมใส่ลิงก์ Apps Script `/exec` ที่ `scriptUrl`
- เพลง ≤ 4 MB, วิดีโอ ≤ 10 MB, ใช้ไฟล์ที่มีสิทธิ์ใช้งานเท่านั้น
- หน้าแอดมินไม่มีรหัสผ่าน แต่ไม่มีใครเผยแพร่ได้ถ้าไม่มี token ของคุณ
