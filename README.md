# Lee & Praew · เว็บงานแต่ง (v9)

หน้าแรกเป็นซองจดหมาย แตะเพื่อเปิด → วิดีโอเปิดซอง (ซองเปิด → คลิป → โลโก้) → เข้า Save the Date
ลำดับในเว็บ: ซอง → 01 Save the Date → 02 การ์ดเชิญ → 03 กำหนดการ → 04 Dress code → 05 แถบฟิล์ม → 06 RSVP → ปิดท้าย → ท้ายหน้า
เลื่อนแล้วแต่ละส่วนขยับตาม (แบบ cora): ดูหัวข้อ "motion ตอนเลื่อน" ด้านล่าง

## ไฟล์
- `index.html` หน้าเว็บ
- `admin.html` หน้าแก้ไขทุกอย่าง (ข้อความ รูป สี เพลง วิดีโอ เปิด/ปิดแต่ละส่วน) พร้อมดูตัวอย่างสด
- `config.js` ข้อมูลทั้งหมดของเว็บ (หน้า admin สร้างไฟล์นี้ให้)
- `icons.js` ไอคอนลายเส้น (กาน้ำชา กล่องแหวน คิวปิด ฯลฯ)
- `fonts/` ฟอนต์ที่ใช้ เก็บไว้ในเว็บเอง (โหลดเร็ว ไม่ต้องพึ่ง Google Fonts) พร้อมใบอนุญาต `OFL.txt`
- `assets/` โลโก้ LP (นิ่ง/เคลื่อนไหว), ไอคอนเว็บ, พื้นผิวกระดาษ, `lenis.min.js`
- `photos/` รูป (`photos/gallery/` = รูปในแถบฟิล์ม)
- `media/` วิดีโอเปิดซองและเพลง (สร้างเมื่อใส่ไฟล์ผ่าน admin)
- `apps-script.gs` โค้ดรับคำตอบ RSVP เข้า Google Sheets
- `qr/` QR ที่ชี้ไปเว็บนี้ + สคริปต์สร้าง QR

## วิดีโอเปิดซอง (admin → "วิดีโอเปิดซองและเพลง")
- `video` แนวตั้ง 9:16 สำหรับมือถือ: ไฟล์เดียว ซองเปิด → คลิป → โลโก้ ยาวราว 10 วินาที แนะนำ 720p ไม่เกิน 4–6 MB
- `videoWide` แนวนอน 16:9 สำหรับจอคอม (ไม่บังคับ ถ้าไม่มี จะแสดงวิดีโอแนวตั้งไว้กลางจอบนพื้นเขียวมะกอก)
- ภาพนิ่งซองปิด (admin → รูปภาพ → "ภาพนิ่งซองปิด") = เฟรมแรกของวิดีโอ ขึ้นทันทีระหว่างที่วิดีโอโหลด
- เฟรมสุดท้ายของวิดีโอ: ค้างโลโก้ราว 1 วินาทีบนพื้นสีเดียว (#5B582C หรือ #F5F2EA) แล้วเว็บจะค่อยๆ เปลี่ยนเข้า Save the Date
- มีปุ่ม "ข้าม" ระหว่างเล่น (กด Esc ได้) ถ้าเล่นวิดีโอไม่ได้ เว็บจะใช้ซองที่วาดไว้ + โลโก้แทนอัตโนมัติ
- ถ้ายังไม่ใส่วิดีโอ: ซองที่วาดไว้เปิด → โลโก้วาดเส้น → เข้าเว็บ
- เพลงประกอบ: ถ้ามีวิดีโอ เพลงจะเริ่มหลังวิดีโอจบ (หรือหลังกดข้าม)

## motion ตอนเลื่อน
| ส่วน | สิ่งที่ขยับ |
|---|---|
| 01 Save the Date / 02 การ์ดเชิญ | ข้อความค่อยๆ ขึ้นทีละชิ้น ตัวเขียนวาดออกมา รูปเลื่อนช้ากว่าหน้า |
| 03 กำหนดการ | หัวข้อค้างกลางจอ เส้นเวลาวาดลงมา แล้วแต่ละช่วงเวลาขึ้นทีละอันตามการเลื่อน |
| 04 Dress code | การ์ดสีซ้อนเป็นปึก แล้วกางออกเป็นพัดตามการเลื่อน |
| 05 แถบฟิล์ม | ฟิล์มวิ่งเอง เร็วขึ้นตามความเร็วที่เลื่อน และวิ่งกลับทางเมื่อเลื่อนขึ้น มีปุ่มหยุด |
| 06 RSVP | ซองค้างกลางจอ ตราหลุด ฝาเปิด การ์ด "Kindly Reply" เลื่อนขึ้น / หลังส่งคำตอบ การ์ดลงซอง ฝาปิด ประทับตรา |
| ปิดท้าย | รูปเลื่อนช้ากว่าหน้า |

ทั้งหมดใช้ CSS + JS ล้วน (ไม่มี WebGL) ลื่นบนมือถือ ถ้าเครื่องตั้ง "ลดการเคลื่อนไหว" ทุกอย่างจะนิ่งและอ่านได้ครบ

## ช่องรูป (เปลี่ยนได้ที่ admin → รูปภาพ)
| ช่อง | อยู่ตรงไหน | แนะนำ | ตอนนี้ |
|---|---|---|---|
| poster | ภาพนิ่งซองปิด (ใช้คู่กับวิดีโอ) | แนวตั้ง 9:16 | ว่าง |
| portrait | การ์ดเชิญ ข้างข้อความ | แนวตั้ง 2:3 | print1.jpg |
| pageBg | พื้นหลังกำหนดการ | รูปวิว/ต้นไม้ แนวตั้ง | bg.jpg (ต้นหลิว) |
| detail | Dress code รูปเล็ก | แนวตั้ง 4:5 | ว่าง |

รูปแถบฟิล์ม: admin → 05 แถบฟิล์ม (เพิ่มได้หลายรูปพร้อมกัน เรียงลำดับ/ลบได้) ตอนนี้ใช้ 14 รูปจากชุด Green
ช่องที่ว่างจะแสดงเป็นกรอบสีเขียวพร้อมโลโก้ หรือปิดทั้งส่วนได้ในหมวดของส่วนนั้น

## ลิงก์พิเศษ
- `?to=ชื่อแขก` ชื่อจะขึ้นบนซอง และกรอกในฟอร์มให้อัตโนมัติ (สร้างได้ใน admin → ซองจดหมาย)
- `?skip` ข้ามซอง (ใช้ทดสอบ)

## อัปโหลดขึ้น GitHub (ครั้งแรกของเวอร์ชันนี้)
1. แตกไฟล์ zip แล้วเปิดโฟลเดอร์ `wedding`
2. ที่ repo บน GitHub กด Add file → Upload files แล้วลากไฟล์และโฟลเดอร์ทั้งหมดข้างในลงไป → Commit changes
3. ลบไฟล์เก่าที่ไม่ใช้แล้วได้: `photos/hero.jpg`
4. รอ 1–2 นาที แล้วเปิดเว็บ (ถ้ายังเห็นของเก่า กด Ctrl+Shift+R หรือเปิดแท็บไม่ระบุตัวตน)

หลังจากนั้นแก้ผ่าน `https://lp222027.github.io/LP_Wedding/admin.html` ได้เลย: กด "เผยแพร่ขึ้นเว็บ" (ใช้ GitHub token สิทธิ์ Contents: Read and write) หรือ "ดาวน์โหลดไฟล์" แล้วอัปโหลดเอง

## RSVP → Google Sheets
ใส่ลิงก์ Apps Script ที่ลงท้ายด้วย `/exec` ใน admin → ข้อมูลงาน → "ลิงก์รับคำตอบ RSVP" ถ้ายังไม่ใส่ ฟอร์มจะเป็นโหมดตัวอย่าง (คำตอบยังไม่ถูกบันทึก)

## เลื่อนนุ่ม (Lenis)
ใช้ไลบรารี Lenis v1.3.28 (MIT) ไฟล์ `assets/lenis.min.js` อยู่ในโปรเจกต์ (~5KB เมื่อบีบอัด)
- มือถือใช้การเลื่อนของเครื่องตามปกติ เมาส์/ทัชแพดบนคอมจะได้ความนุ่ม
- อยากปรับความนุ่ม: แก้ `lerp:.1` ใน index.html (ต่ำ = นุ่มและช้า, สูง = ไวขึ้น)
- รองรับการตั้งค่า "ลดการเคลื่อนไหว" ของมือถือ และใช้คีย์บอร์ดได้ทั้งเว็บ
