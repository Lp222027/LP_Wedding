# Lee & Praew · เว็บงานแต่ง (v8)

หน้าแรกเป็นซองจดหมาย แตะเพื่อเปิด → การ์ดเลื่อนออกจากซอง → เข้าสู่เว็บ
ลำดับในเว็บ: หน้าแรก (รูปเต็มจอ) → 01 Save the Date → 02 การ์ดเชิญ → 03 กำหนดการ → 04 Dress code → 05 แถบฟิล์ม → 06 RSVP → ปิดท้าย → ท้ายหน้า

## ไฟล์
- `index.html` หน้าเว็บ
- `admin.html` หน้าแก้ไขทุกอย่าง (ข้อความ รูป สี เพลง วิดีโอ เปิด/ปิดแต่ละส่วน) พร้อมดูตัวอย่างสด
- `config.js` ข้อมูลทั้งหมดของเว็บ (หน้า admin สร้างไฟล์นี้ให้)
- `icons.js` ไอคอนลายเส้น (กาน้ำชา กล่องแหวน คิวปิด ฯลฯ)
- `fonts/` ฟอนต์ที่ใช้ เก็บไว้ในเว็บเอง (โหลดเร็ว ไม่ต้องพึ่ง Google Fonts) พร้อมใบอนุญาต `OFL.txt`
- `assets/` โลโก้ LP (นิ่ง/เคลื่อนไหว), ไอคอนเว็บ, พื้นผิวกระดาษ
- `photos/` รูป
- `apps-script.gs` โค้ดรับคำตอบ RSVP เข้า Google Sheets
- `qr/` QR ที่ชี้ไปเว็บนี้ + สคริปต์สร้าง QR

## ช่องรูป (เปลี่ยนได้ที่ admin → รูปภาพ)
| ช่อง | อยู่ตรงไหน | แนะนำ | ตอนนี้ |
|---|---|---|---|
| hero | หน้าแรกเต็มจอ | แนวนอน/แนวตั้ง กว้าง 1600px+ | hero.jpg |
| portrait | การ์ดเชิญ ข้างข้อความ | แนวตั้ง 2:3 | print1.jpg |
| pageBg | พื้นหลังกำหนดการ | รูปวิว/ต้นไม้ แนวตั้ง | bg.jpg (ต้นหลิว) |
| detail | Dress code รูปเล็ก | แนวตั้ง 4:5 | ว่าง |
| film1–3 | แถบฟิล์ม 3 ใบ | แนวตั้ง 4:5 | ว่าง |
| closing | แถบปิดท้ายเต็มจอ | แนวนอน กว้าง 1600px+ | ว่าง |

ช่องที่ว่างจะแสดงเป็นกรอบสีเขียวพร้อมโลโก้ (ในหน้าตัวอย่างของ admin มีเส้นประบอกตำแหน่ง) หรือปิดทั้งส่วนได้ในหมวดของส่วนนั้น

## ลิงก์พิเศษ
- `?to=ชื่อแขก` ชื่อจะขึ้นบนซอง และกรอกในฟอร์มให้อัตโนมัติ (สร้างได้ใน admin → ซองจดหมาย)
- `?skip` ข้ามซอง (ใช้ทดสอบ)

## อัปโหลดขึ้น GitHub (ครั้งแรกของเวอร์ชันนี้)
1. แตกไฟล์ zip แล้วเปิดโฟลเดอร์ `wedding`
2. ที่ repo บน GitHub กด Add file → Upload files แล้วลากไฟล์และโฟลเดอร์ทั้งหมดข้างในลงไป → Commit changes
3. รอ 1–2 นาที แล้วเปิดเว็บ (ถ้ายังเห็นของเก่า กด Ctrl+Shift+R หรือเปิดแท็บไม่ระบุตัวตน)

หลังจากนั้นแก้ผ่าน `https://lp222027.github.io/LP_Wedding/admin.html` ได้เลย: กด "เผยแพร่ขึ้นเว็บ" (ใช้ GitHub token สิทธิ์ Contents: Read and write) หรือ "ดาวน์โหลดไฟล์" แล้วอัปโหลดเอง

## RSVP → Google Sheets
ใส่ลิงก์ Apps Script ที่ลงท้ายด้วย `/exec` ใน admin → ข้อมูลงาน → "ลิงก์รับคำตอบ RSVP" ถ้ายังไม่ใส่ ฟอร์มจะเป็นโหมดตัวอย่าง (คำตอบยังไม่ถูกบันทึก)

## หมายเหตุ
- เพลงเริ่มเมื่อแขกแตะเปิดซอง มีปุ่มเปิด/ปิดมุมขวาล่าง (ใช้เพลงที่มีสิทธิ์ใช้ ≤ 4 MB)
- วิดีโอแทนรูปหน้าแรกได้ (≤ 10 MB) มีปุ่มหยุดให้แขก
- รองรับการตั้งค่า "ลดการเคลื่อนไหว" ของมือถือ และใช้คีย์บอร์ดได้ทั้งเว็บ
