เผยแพร่ขึ้นเว็บ

ส่งการแก้ไขขึ้น GitHub โดยตรง เว็บจริงจะอัปเดตภายใน 1–2 นาที

วิธีสร้างโทเค็น (ทำครั้งเดียว)
  1. เปิด github.com/settings/personal-access-tokens/new
  2. ตั้งชื่อ เช่น wedding-admin และเลือกวันหมดอายุ
  3. Repository access → Only select repositories → เลือก repo เว็บงานแต่ง
  4. Permissions → Repository permissions → Contents: Read and write
  5. กด Generate token แล้วคัดลอกมาวางด้านบน (ห้ามแชร์โทเค็นให้ใคร)
